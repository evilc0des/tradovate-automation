# NinjaTrader Bridge Skeleton

This folder contains the NinjaTrader-side execution bridge scaffolding and DTOs used for local integration.

## Planned modules
- `BridgeConfig.cs`
- `Dtos.cs`
- `SignalValidator.cs`
- `DedupStore.cs`
- `RiskEngine.cs`
- `ExecutionBridge.cs`

Import these into your NinjaTrader custom project and wire into strategy/add-on lifecycle callbacks.
